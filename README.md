# AI-Driven Multimodal Neurological Monitoring System

## Description
This project was developed during the FOSSEE Open Source Hardware Hackathon 2026 conducted by IIT Bombay.

The project focuses on an AI-driven multimodal neurological monitoring system integrating EEG (brain activity), EMG (muscle signals), PPG (heart rate), and IMU (motion tracking). The goal is to process biosignals in real time and generate meaningful insights for monitoring and early detection.

## Technologies Used
- ESP32
- Arduino
- AI/ML Concepts
- Sensor Integration
- Signal Processing

## Features
- Real-time biosignal monitoring
- EEG, EMG, PPG, and IMU integration
- Data acquisition and processing
- Prototype for healthcare applications
